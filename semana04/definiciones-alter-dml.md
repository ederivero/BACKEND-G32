`ALTER TABLE nombre_tabla`

| Operación | Comando |
|---|---|
| Agregar columna | `ADD COLUMN nombre TIPO` |
| Quitar columna | `DROP COLUMN nombre [CASCADE]` |
| Cambiar tipo | `ALTER COLUMN nombre TYPE TIPO [USING expresion]` |
| Renombrar columna | `RENAME COLUMN vieja TO nueva` |
| Renombrar tabla | `RENAME TO nueva_tabla` |
